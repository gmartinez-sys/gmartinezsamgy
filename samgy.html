Presentación del Proyecto

En el área de enfermería del Colegio San Alberto Magno, la gestión suele llevarse a cabo de forma manual[cite: 1]. SAMGY nace para centralizar, estructurar y optimizar la información médica y académica[cite: 1].

Objetivos de SAMGY

  • Crear una base de datos digital estudiantil[cite: 1].
  • Facilitar consultas rápidas de enfermería[cite: 1].
  • Reducir el uso de registros en papel[cite: 1].
  • Generar reportes y actualizar fichas periódicamente[cite: 1].

Herramientas Tecnológicas Implementadas

• HTML5 & CSS3: Para maquetación visual basada en la identidad de marca[cite: 1].
• JavaScript: Para la lógica de interacción y búsquedas.
• Git & GitHub: Control de versiones y despliegue continuo.
